# PIXO Frontend

واجهة متجر عربية باتجاه RTL مبنية باستخدام Next.js وTypeScript. المنتجات والطلبات والسلة تُحفظ محليًا في المتصفح، ولا يحتاج تشغيل المتجر إلى خدمة قاعدة بيانات.

## التشغيل

من مجلد `frontend`:

```powershell
npm install
npm run dev
```

افتح `http://localhost:3001`.

## إدارة المتجر

- المنتجات التجريبية تظهر في الصفحة الرئيسية تلقائيًا.
- افتح `/admin` وسجّل الدخول بالبريد `admin@pixo.local` وكلمة مرور غير فارغة.
- أضف المنتجات من `/admin/products/new`؛ تظهر فورًا في واجهة المتجر وتُحفظ في المتصفح نفسه.
- صفحة إتمام الطلب تحسب الشحن وتقبل عنوانًا مفصلًا. الطلبات وحالاتها التجريبية محفوظة محليًا، ويمكن تتبع طلب الزائر برقم الهاتف ورقم الطلب.

البيانات المحلية لا تنتقل إلى أجهزة أو متصفحات أخرى، ولا تُرسل الطلبات إلى شركة شحن أو نظام دفع.

## النشر

تطبيق Next.js موجود داخل `frontend`. عند النشر على Vercel، اضبط **Root Directory** على `frontend`.
